# Modern Wellness

Static website for the Framingham Longevity Spa and Westwood Recovery Room. Public source is in `dist/`; no build dependencies or environment variables are needed. Vercel serves `dist/` using `vercel.json` and redirects retired service URLs to location services.

Pricing uses native accessible disclosure sections: compact on phones, expanded on larger screens. FAQs, policy PDFs, and parking PDFs are hosted locally. Policy wording was carried over from the published Modern Wellness website.

Newsletter signup currently opens a clearly labeled email request to hello@modernwellspa.com; it does not enroll automatically. Connect a mailing-list provider to replace that flow with automatic signup.

Booking links use the existing booking app. Video uses click-to-load Google Drive previews; mobile player improvements are deferred. Photography and films: Alex Moore.

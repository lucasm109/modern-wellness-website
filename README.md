# Modern Wellness

Static website for the Framingham Longevity Spa and Westwood Recovery Room.

## Source

All public HTML, CSS, JavaScript, and optimized imagery live in `dist/`. The site has no build dependencies, server code, or required environment variables.

## Deploy to Vercel

Import this GitHub repository into Vercel. Use the repository root as the project root. `vercel.json` selects the Other/static framework, skips dependency installation and builds, and serves `dist/`.

Keep the existing HTML filenames when editing links. No single-page-app rewrite is required.

## External services

Booking links lead to the existing Modern Wellness booking application. Video sections embed Google Drive previews and require the source videos to remain accessible to visitors. Newsletter signup, parking guides, and policy links currently point to the existing Modern Wellness Wix website. Move those resources before retiring that website.

## Content

The two locations have distinct prices and access models. Shared services use location-specific pages and photographs. Photography and films are credited to Alex Moore.
